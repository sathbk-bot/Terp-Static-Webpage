The Evolution of Sorting Algorithms

Different strategies for turning unordered data into useful information.

Why Sorting Matters

Sorting places data into a meaningful order. Once information is sorted, searching, comparing, and displaying it can become much easier. The best algorithm depends on the size, type, and existing order of the data.

Eight Important Approaches

QuickSort

QuickSort selects a pivot, separates smaller and larger values, and repeats the process on each partition. It is often fast for in-memory data, but poor pivot choices can produce its quadratic worst case.

MergeSort

MergeSort divides data into smaller pieces, sorts those pieces, and merges them back together. Its running time is predictable, and its stable behavior is useful when equal values must keep their order.

Radix Sort

Radix Sort groups values by individual digits or positions instead of comparing pairs of values. It works well for integers and other keys with a fixed representation.

HeapSort

HeapSort arranges the data into a heap, repeatedly removes the largest value, and places it into its final position. It provides reliable performance while using very little extra memory.

Counting Sort

Counting Sort records how many times each value occurs and uses those counts to rebuild the data in order. It is useful when the input contains integers from a reasonably small range.

Bubble Sort

Bubble Sort repeatedly compares neighboring values and swaps them when they are out of order. It is easy to understand, but it becomes inefficient as the amount of data grows.

Insertion Sort

Insertion Sort builds a sorted section one value at a time. Each new value is moved left until it reaches its correct position. It works especially well for small or nearly sorted collections.

Selection Sort

Selection Sort repeatedly finds the smallest remaining value and moves it into the next open position. It performs few swaps, but it still makes many comparisons as the collection grows.

Big-O Complexity Cheat Sheet

Algorithm Best Time Average Time Worst Time
QuickSort O(n log n) O(n log n) O(n2)
MergeSort O(n log n) O(n log n) O(n log n)
Radix Sort O(nd) O(nd) O(nd)
HeapSort O(n log n) O(n log n) O(n log n)
Counting Sort O(n + k) O(n + k) O(n + k)
Bubble Sort O(n) O(n2) O(n2)
Insertion Sort O(n) O(n2) O(n2)
Selection Sort O(n2) O(n2) O(n2)

Notation: n is the number of values, d is the number of digit passes, and k is the range of values.
